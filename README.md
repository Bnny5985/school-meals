# הקופסה 🥪

אתר לתכנון ארוחות בוקר, צהריים ופינוק ליום שישי לילדי בית ספר יסודי (א׳–ו׳),
עם התחשבות באלרגנים האסורים בבית הספר.

**60 מנות** · עברית מלאה (RTL) · ערכים תזונתיים · עובד בנייד · מצב כהה ובהיר · בלי שרת ובלי מסד נתונים

עיצוב בהשראת תבנית **FreshEat** — הצבעים, הטיפוגרפיה וצורות הכרטיסים אומצו ממנה,
אבל ה-CSS נכתב מחדש RTL מלכתחילה (התבנית המקורית היא Bootstrap LTR).

## 📸 תמונות

כל 67 התמונות נוצרו מקומית ב-**ComfyUI** עם **Flux.1-schnell**, בסגנון צילום
מוצר אחיד: צלחת לבנה, רקע קרם בגוון `--bg2` של האתר, תאורה כיוונית רכה.

```bash
node tools/generate-images.mjs                 # הכול
node tools/generate-images.mjs --only hero     # רק 7 הראשיות
node tools/generate-images.mjs --id tuna-sandwich --force
```

דורש ComfyUI פעיל ב-8188 ואת `flux1-schnell-fp8.safetensors` בתיקיית
`models/checkpoints`. הפרומפטים ב-`tools/image-prompts.js`.

### ⚠️ שכבת הבטיחות — ולמה היא בפרומפט החיובי

בריצה הראשונה התגלתה בעיה: **Flux schnell מחייב `cfg=1.0`, ובערך הזה המודל
מתעלם כמעט לחלוטין מ-negative prompt.** התוצאה הייתה קשיו על הבראוניז,
אגוז על עוגת היוגורט ואגוזים סביב הפופקורן — למרות שכולם היו ברשימת השלילה.

הפתרון: שכבת הבטיחות עברה ל**פרומפט החיובי** (`CLEAN` ב-`image-prompts.js`),
מנוסחת בשפה חיובית כי מודלים מתמודדים גרוע עם שלילה:

> *"the food is completely plain and bare… absolutely nothing scattered on top
> or around it, no garnish, no toppings, no seeds, no nuts of any kind"*

בנוסף יש תוספת ייעודית למאפים מתוקים (`SWEET_EXTRA`) וללחמים (`BREAD_EXTRA`) —
שתי הקטגוריות שבהן המודל הכי נוטה להוסיף אגוזים וזרעים.

> **אל תוסיף תמונה בלי להסתכל עליה.** הרץ `python tools/contact-sheet.py`
> ועבור על הגיליונות. תמונה שסותרת את רשימת האלרגנים מסוכנת יותר מאשר אין תמונה בכלל.

התמונות להמחשה בלבד ואינן תצלום של המנה שתכין. רשימת הקבצים ב-**[IMAGES.md](IMAGES.md)**.
האתר עדיין מציג איור וקטורי בכל מקום שחסרה בו תמונה.

## 🍎 ערכים תזונתיים

כל דף מנה מציג קלוריות, חלבון וסוכר, ולצד כל אחד את **אחוז הצריכה היומית**
של ילד/ה בבית ספר יסודי.

ערכי הייחוס (ב-`data/config.js` תחת `nutritionRef`):

| ערך | ליום | מקור |
|---|---|---|
| קלוריות | 1,800 קק״ל | ממוצע גילאי 6–12, טווח אמיתי 1,600–2,000 |
| חלבון | 35 גר׳ | כ-0.95 גר׳ לק״ג · ילד במשקל 30 ק״ג |
| סוכר | 25 גר׳ | המלצת איגוד הלב האמריקאי לילדים |

הצבע משתנה לפי הערך: סוכר מעל 60% מהיומי נצבע אדום, חלבון מעל 25% נצבע ירוק.

> ⚠️ **המספרים הם הערכה מחושבת לפי כמויות המרכיבים, לא בדיקת מעבדה.**
> הם משתנים לפי המותג, גודל הפרוסה וכמה נדיב אתה עם הממרח. סדר גודל, לא דיוק.
> לעריכה: `data/nutrition.js`, או דרך פאנל הניהול.

## עדכון האלרגנים — ילד חדש הצטרף לכיתה

**הדרך הקלה:** פתח את `local-admin/admin.html` בדפדפן ← לשונית **אלרגנים** ← מלא שם, מזהה
ומילים נרדפות ← **הוסף אלרגן**. אחר כך לשונית **ייצוא** ← הורד את קטע האלרגנים
והדבק אותו ב-`data/config.js`.

**הדרך הישירה:** ערוך את `data/config.js` והוסף שורה למערך `allergens`:

```js
{ id: "hazelnut", name: "אגוזי לוז", aliases: ["אגוז לוז", "לוז", "hazelnut"], active: true },
```

כל האתר מתעדכן מיד: פס האזהרה בראש כל עמוד, כל דפי המנות, וסורק המוצרים.

> ילד עזב? עדיף לשנות `active: true` ל-`active: false` מאשר למחוק — כך נשמרת ההיסטוריה.

> ⚠️ **אם פתחת את פאנל הניהול בעבר ושמרת טיוטה** — הטיוטה שמורה בדפדפן שלך ומכילה
> את רשימת האלרגנים הישנה, והיא תסתיר את הקובץ המעודכן. היכנס ל-`local-admin/admin.html`
> ולחץ **״בטל שינויים״** כדי לטעון את הרשימה החדשה.

## עריכת מנות

פתח את `local-admin/admin.html`, בחר מנה מהרשימה, ערוך, לחץ **עדכן מנה**.
השינויים נשמרים בדפדפן שלך בלבד — כדי שיופיעו באתר האמיתי:

1. לשונית **ייצוא** ← הורד את קובץ הקטגוריה (ואת `nutrition.js` אם שינית ערכים תזונתיים)
2. העתק אותו לתיקיית `data/` במקום הישן
3. העלה ל-GitHub
4. חזור לפאנל ולחץ **בטל שינויים** (כדי שהטיוטה לא תסתיר את הקובץ החדש)

### פורמט רשימת המוצרים

בשדה "מוצרים להכין מראש", שורה לכל מוצר:

```
שם המוצר | כמות | הערה | אזהרת אלרגן
```

הערה ואזהרה אופציונליות. האזהרה מוצגת כמשולש כתום ליד המוצר.

### הערות אלרגנים

שורה שמתחילה ב-`❌` מוצגת באדום, שורה שמתחילה ב-`⚠️` בכתום, כל השאר באפור.

**תבנית FreshEat** (Envato) שימשה כהשראה עיצובית בלבד. אף קובץ שלה אינו חלק
מהריפו הזה — היא מוחרגת ב-`.gitignore`, ורישיון Envato אינו מתיר הפצה מחדש.
ה-CSS באתר נכתב מאפס.

### הבהרה

הערכים התזונתיים באתר הם הערכות, והמידע על אלרגנים הוא עזר בלבד —
**אין תחליף לקריאת התווית על האריזה.** הרישיון ניתן "כמות שהוא", ללא אחריות.
